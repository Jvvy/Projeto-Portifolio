# Meu Portfólio

Portfólio pessoal desenvolvido com **HTML5 e CSS3** como parte dos meus estudos em desenvolvimento web. O projeto tem como objetivo praticar a estruturação de páginas, estilização de componentes e criação de layouts responsivos.

## ✨ Funcionalidades

- Navegação entre as seções Home, Sobre e Projetos.
- Menu de navegação fixo durante a rolagem da página.
- Seção de apresentação pessoal.
- Galeria visual para exibição de projetos.
- Efeitos de interação com CSS, incluindo `hover` e transições.
- Layout responsivo para diferentes tamanhos de tela.
- Rolagem suave entre as seções.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, Flexbox, media queries, transições e efeitos visuais.
- **Google Fonts:** utilização de fonte externa para a identidade visual.

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/Jvvy/Projeto-Portifolio.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Projeto-Portifolio
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para visualizar a página localmente.

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei conceitos importantes de desenvolvimento front-end, como:

- Estruturação semântica com HTML.
- Organização de estilos em um arquivo CSS separado.
- Construção de layouts utilizando Flexbox.
- Adaptação de componentes para dispositivos móveis com media queries.
- Criação de efeitos visuais e interações com CSS.
- Organização de arquivos e recursos do projeto.
